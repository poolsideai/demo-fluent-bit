# win874_to_utf8.map

## Overview

This file contains a mapping table that converts characters from the Windows code page 874 (Thai) encoding to UTF-8 encoding. It is part of Fluent Bit's Unicode conversion system that handles character encoding transformations for international text processing.

## Key Components

### Data Structures

#### `win874_to_unicode_tree_table`
- A static array of 248 uint32_t values representing the mapping from CP874 to Unicode code points
- Contains mappings for all characters in the CP874 character set (0x80-0xFB range)
- Uses a radix tree structure for efficient lookup

#### `win874_to_unicode_tree`
- A radix tree structure that defines the mapping parameters
- Contains metadata about the mapping table including:
  - Start offset (0x007c)
  - Range boundaries (0x80 to 0xfb)
  - Table size information

## Important Variables

### Mapping Table Entries
- Entries from 0x80-0xFB map CP874 characters to their Unicode equivalents
- Characters in the 0x00-0x7F range use standard ASCII mappings
- Thai characters and special symbols are mapped appropriately

## Dependencies

- Part of the Fluent Bit Unicode conversion system
- Used by the `flb_conv.c` module for character encoding transformations
- Generated by `src/unicode/maps/UCS_to_most.py` script

## Implementation Details

### Radix Tree Structure
The mapping uses a radix tree approach for efficient character conversion:
- Dummy entries (0x00000000) for invalid character ranges
- Direct mappings for valid CP874 characters to Unicode code points
- Efficient lookup with O(1) complexity for single-byte characters

### Character Mapping Examples
- CP874 0x80 → Unicode U+20AC (Euro Sign)
- CP874 0xA0 → Unicode U+00A0 (No-Break Space)
- CP874 0xE0 → Unicode U+0E01 (Thai Character Ko Kai)

## Usage

This mapping table is automatically used by Fluent Bit's Unicode conversion system when processing text data that needs to be converted from CP874 encoding to UTF-8. The conversion happens transparently during log processing when the appropriate character encoding is detected.
