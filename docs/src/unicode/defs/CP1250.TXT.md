# CP1250.TXT

## Overview

This file contains the character mapping table for Windows-1250 encoding to Unicode. Windows-1250 is a character encoding standard developed by Microsoft for representing Central and Eastern European languages including Polish, Czech, Slovak, Hungarian, Romanian, Croatian, Slovenian, and Serbian.

The file defines the mapping between Windows-1250 code points and their corresponding Unicode code points. It follows the standard Format A specification with three tab-separated columns.

## Key Information

### File Details
- **Name**: cp1250 to Unicode table
- **Unicode version**: 2.0
- **Table version**: 2.01
- **Table format**: Format A
- **Date**: 04/15/98
- **Contact**: Shawn.Steele@microsoft.com

### Format
The file uses Format A with three tab-separated columns:
1. **cp1250 code** (in hex)
2. **Unicode code** (in hex as 0xXXXX)
3. **Unicode name** (follows a comment sign, '#')

## Important Notes

### Control Characters
Codes 0x00-0x1F and 0x7F represent standard ASCII control characters with their corresponding Unicode mappings.

### Undefined Characters
Several code points are undefined and marked with empty Unicode mappings:
- `0x81`: UNDEFINED
- `0x83`: UNDEFINED
- `0x88`: UNDEFINED
- `0x90`: UNDEFINED
- `0x98`: UNDEFINED
- `0x9A`: UNDEFINED
- `0x9D`: UNDEFINED
- `0x9E`: UNDEFINED
- `0xFF`: UNDEFINED

These undefined characters should be handled appropriately in conversion routines.

## Usage Examples

Converting CP1250 to Unicode:
```c
// Using the mapping table in code
uint8_t cp1250_code = 0x8A;  // Windows-1250 code for LATIN CAPITAL LETTER S WITH CARON
uint16_t unicode_code = lookup_cp1250_to_unicode(cp1250_code);  // Returns 0x0160
```

Converting Unicode to CP1250:
```c
// Reverse lookup (requires building reverse mapping)
uint16_t unicode_code = 0x0160;  // LATIN CAPITAL LETTER S WITH CARON
uint8_t cp1250_code = lookup_unicode_to_cp1250(unicode_code);  // Returns 0x8A
```
