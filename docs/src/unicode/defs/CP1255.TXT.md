# CP1255.TXT Documentation

## Overview

This file contains a mapping table between the Code Page 1255 (Hebrew) character encoding and Unicode. Code Page 1255 is a single-byte character encoding used primarily for Hebrew text in Microsoft Windows environments.

## File Structure

The file follows a standardized format with three tab-separated columns:
1. **Column 1**: CP1255 code (in hexadecimal format)
2. **Column 2**: Unicode code point (in hexadecimal format as 0xXXXX)
3. **Column 3**: Unicode character name (following a comment sign '#')

## Key Components

### Character Mapping
The table maps CP1255 character codes to their corresponding Unicode code points. This enables conversion between the legacy CP1255 encoding and modern Unicode representations.

### Special Characters
- Control characters (0x00-0x1F)
- Basic Latin characters (0x20-0x7F)
- Hebrew-specific characters including:
  - Hebrew letters (0xE0-0xFA)
  - Hebrew punctuation marks
  - Hebrew diacritical marks
- Extended characters for Hebrew text processing

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Hebrew text encoding conversions. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- Format A table structure
- Entries ordered by CP1255 code sequence
- Undefined characters marked with empty values

### Character Ranges
- ASCII range (0x00-0x7F): Standard ASCII characters
- Hebrew range (0x80-0xFF): Hebrew-specific characters
- Special handling for undefined/reserved code points

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain CP1255-encoded Hebrew characters. The system uses this table to convert between CP1255 and Unicode representations as needed for proper text processing and transmission.
