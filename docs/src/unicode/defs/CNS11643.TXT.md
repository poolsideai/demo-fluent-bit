# CNS11643.TXT

## Overview

This file contains the character mapping table for CNS 11643-1986 encoding to Unicode. CNS 11643 is a Chinese character encoding standard developed by the Chinese government for representing Traditional Chinese characters.

The file defines the mapping between CNS 11643 code points and their corresponding Unicode code points. It includes special notes about characters that cannot be mapped due to conflicts or duplicate representations.

## Key Information

### File Details
- **Name**: CNS 11643-1986 to Unicode table (complete)
- **Unicode version**: 1.1
- **Table version**: 2.0
- **Table format**: Format A
- **Date**: 2011 October 14 (header updated: 2015 December 02)

### Format
The file uses Format A with three tab-separated columns:
1. **CNS 11643 code** (in hex as 0xXXXXX)
2. **Unicode code** (in hex as 0xXXXX)
3. **Unicode name** (follows a comment sign, '#')

For CJK Unified Ideographs (U+4E00 to U+9FA5), the token "<CJK>" is used instead of the full name to reduce file size.

## Important Notes

### Unmappable Characters
Several characters cannot be mapped due to conflicts or duplicate representations:
- `0x12224`: SPACING HEAVY OVERSCORE (not in Unicode)
- `0x12226`: SPACING HEAVY UNDERSCORE (not in Unicode)

### Duplicate Characters
Some characters are not mapped because CNS 11643 includes duplicate versions of some ideographs which are included in Unicode only once:
- `0x1243E` through `0x12440`: HANGZHOU NUMERAL TEN, TWENTY, and THIRTY
- `0x12721` through `0x12939`: KangXi radical set

These characters are intentionally excluded from the mapping table.

### Special Character Mapping
The CNS 11643 character `0x1256D` (tone mark for first Mandarin tone) is mapped to U+02C9 MODIFIER LETTER MACRON. However, since bopomofo uses absence of tone mark for first tone, U+2003 EM SPACE might be preferred in some implementations.

## Notable Implementation Details

1. **Complete Mapping**: Contains one set of mappings from CNS 11643-1986 into Unicode
2. **Round-trip Compatibility Warning**: It's impossible to provide round-trip compatibility between CNS 11643-1986 and Unicode
3. **CJK Optimization**: Uses "<CJK>" token for CJK Unified Ideographs to reduce file size
4. **Duplicate Handling**: Explicitly excludes duplicate character mappings
5. **Version Tracking**: Maintains revision history with dates and changes

## Usage Examples

Converting CNS 11643 to Unicode:
```c
// Using the mapping table in code
uint16_t cns_code = 0x12121;  // CNS 11643 code for IDEOGRAPHIC SPACE
uint16_t unicode_code = lookup_cns_to_unicode(cns_code);  // Returns 0x3000
```

Converting Unicode to CNS 11643:
```c
// Reverse lookup (requires building reverse mapping)
uint16_t unicode_code = 0x3000;  // IDEOGRAPHIC SPACE
uint16_t cns_code = lookup_unicode_to_cns(unicode_code);  // Returns 0x12121
```
