# windows-949-2000.xml Documentation

## Overview

This file contains a mapping table between the Windows-949 (Korean) character encoding and Unicode. Windows-949 is a double-byte character encoding used primarily for Korean text in Microsoft Windows environments. It's an extension of the EUC-KR encoding and supports a broader range of Korean characters.

## File Structure

This file uses an XML format based on the Unicode Character Mapping DTD (Document Type Definition). The structure includes:
- Character mapping definitions with validity states
- Assignment tables with Unicode to byte sequence mappings
- Special handling for multi-byte sequences

## Key Components

### Mapping Structure
The file defines mappings between Unicode code points and their corresponding Windows-949 byte sequences. This enables conversion between the legacy Windows-949 encoding and modern Unicode representations.

### Special Features
- Support for single-byte and double-byte sequences
- Comprehensive coverage of Korean characters including:
  - ASCII characters (single-byte)
  - Hangul syllables (double-byte)
  - Hanja characters (double-byte)
  - Symbols and punctuation marks
- Special encoding for user-defined areas

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Korean text encoding conversions according to the Windows-949 standard. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- XML-based character mapping format
- Validity state definitions for different byte ranges
- Special handling for multi-byte character sequences

### Character Encoding Ranges
- Single-byte range (0x00-0x7F): ASCII characters
- Double-byte range (0x81-0xFE): Korean characters
  - Hangul syllables (0x8141-0xC6FE)
  - Hanja characters (0xC9A1-0xF9FE)

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain Windows-949-encoded Korean characters. The system uses this table to convert between Windows-949 and Unicode representations as needed for proper text processing and transmission in Microsoft Windows environments.
