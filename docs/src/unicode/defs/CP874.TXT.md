# CP874.TXT Documentation

## Overview

This file contains a mapping table between the Code Page 874 (Thai) character encoding and Unicode. Code Page 874 is a single-byte character encoding used primarily for Thai text in Microsoft Windows environments. It supports the Thai script and is based on the TIS-620 standard.

## File Structure

The file follows a standardized format with three tab-separated columns:
1. **Column 1**: CP874 code (in hexadecimal format)
2. **Column 2**: Unicode code point (in hexadecimal format as 0xXXXX)
3. **Column 3**: Unicode character name (following a comment sign '#')

## Key Components

### Character Mapping
The table maps CP874 character codes to their corresponding Unicode code points. This enables conversion between the legacy CP874 encoding and modern Unicode representations.

### Special Characters
- Control characters (0x00-0x1F)
- Basic Latin characters (0x20-0x7F)
- Thai-specific characters including:
  - Thai consonants (0xA1-0xDA)
  - Thai vowels (0xD0-0xF9)
  - Thai tone marks and diacritical signs
  - Thai punctuation marks
- Currency symbols and special characters

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Thai text encoding conversions. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- Format A table structure
- Entries ordered by CP874 code sequence
- Special handling for Thai combining characters

### Character Ranges
- ASCII range (0x00-0x7F): Standard ASCII characters
- Thai range (0x80-0xFF): Thai-specific characters
- Tone marks and vowel signs for proper Thai text rendering

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain CP874-encoded Thai characters. The system uses this table to convert between CP874 and Unicode representations as needed for proper text processing and transmission.
