# CP1253.TXT

## Overview

This file contains the character mapping table for Windows-1253 encoding to Unicode. Windows-1253 is a character encoding standard developed by Microsoft for representing Greek language characters.

The file defines the mapping between Windows-1253 code points and their corresponding Unicode code points. It follows the standard Format A specification with three tab-separated columns.

## Key Information

### File Details
- **Name**: cp1253 to Unicode table
- **Unicode version**: 2.0
- **Table version**: 2.01
- **Table format**: Format A
- **Date**: 04/15/98
- **Contact**: Shawn.Steele@microsoft.com

### Format
The file uses Format A with three tab-separated columns:
1. **cp1253 code** (in hex)
2. **Unicode code** (in hex as 0xXXXX)
3. **Unicode name** (follows a comment sign, '#')

## Important Notes

### Control Characters
Codes 0x00-0x1F and 0x7F represent standard ASCII control characters with their corresponding Unicode mappings.

### Undefined Characters
Several code points are undefined and marked with empty Unicode mappings:
- `0x81`: UNDEFINED
- `0x83`: UNDEFINED
- `0x88`: UNDEFINED
- `0x90`: UNDEFINED
- `0x98`: UNDEFINED
- `0x9A`: UNDEFINED
- `0x9D`: UNDEFINED
- `0x9E`: UNDEFINED
- `0xFF`: UNDEFINED

These undefined characters should be handled appropriately in conversion routines.

### Greek Character Set
Windows-1253 supports the complete Greek alphabet with diacritical marks:
- Uppercase Greek letters: ΑΒΓΔΕΖΗΘΙΚΛΜΝΞΟΠΡΣΤΥΦΧΨΩ
- Lowercase Greek letters: αβγδεζηθικλμνξοπρστυφχψω
- Diacritical marks: άέήίόύώϊϋΐΰ

## Usage Examples

Converting CP1253 to Unicode:
```c
// Using the mapping table in code
uint8_t cp1253_code = 0xE1;  // Windows-1253 code for GREEK SMALL LETTER ALPHA
uint16_t unicode_code = lookup_cp1253_to_unicode(cp1253_code);  // Returns 0x03B1
```

Converting Unicode to CP1253:
```c
// Reverse lookup (requires building reverse mapping)
uint16_t unicode_code = 0x03B1;  // GREEK SMALL LETTER ALPHA
uint8_t cp1253_code = lookup_unicode_to_cp1253(unicode_code);  // Returns 0xE1
```
