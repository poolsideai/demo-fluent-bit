# CP1252.TXT

## Overview

This file contains the character mapping table for Windows-1252 encoding to Unicode. Windows-1252 is a character encoding standard developed by Microsoft as an extension of ISO 8859-1 (Latin-1) for Western European languages including English, French, German, Spanish, Portuguese, Dutch, and others.

The file defines the mapping between Windows-1252 code points and their corresponding Unicode code points. It follows the standard Format A specification with three tab-separated columns.

## Key Information

- **Table version**: 2.01
- **Table format**: Format A
- **Date**: 04/15/98
- **Contact**: Shawn.Steele@microsoft.com

### Format
The file uses Format A with three tab-separated columns:
1. **cp1252 code** (in hex)
2. **Unicode code** (in hex as 0xXXXX)
3. **Unicode name** (follows a comment sign, '#')

## Important Notes

### Control Characters
Codes 0x00-0x1F and 0x7F represent standard ASCII control characters with their corresponding Unicode mappings.

### Undefined Characters
Several code points are undefined and marked with empty Unicode mappings:
- `0x81`: UNDEFINED
- `0x83`: UNDEFINED
- `0x88`: UNDEFINED
- `0x90`: UNDEFINED
- `0x98`: UNDEFINED
- `0x9A`: UNDEFINED
- `0x9D`: UNDEFINED
- `0x9E`: UNDEFINED
- `0xFF`: UNDEFINED

These undefined characters should be handled appropriately in conversion routines.

### Compatibility Characters
Windows-1252 extends ISO 8859-1 by adding printable characters in the range 0x80-0x9F:
- `0x80`: EURO SIGN (€)
- `0x82`: SINGLE LOW-9 QUOTATION MARK (‚)
- `0x84`: DOUBLE LOW-9 QUOTATION MARK („)
- `0x85`: HORIZONTAL ELLIPSIS (…)
- `0x86`: SINGLE LEFT-POINTING ANGLE QUOTATION MARK (‹)
- `0x87`: SINGLE RIGHT-POINTING ANGLE QUOTATION MARK (›)
- `0x89`: PER MILLE SIGN (‰)
- `0x8A`: LATIN CAPITAL LETTER S WITH CARON (Š)
- `0x8B`: SINGLE LEFT-POINTING ANGLE QUOTATION MARK (‹)
- `0x8C`: LATIN CAPITAL LETTER Z WITH CARON (Ž)
- `0x8E`: LATIN CAPITAL LETTER Z WITH CARON (Ž) - duplicate
- `0x91`: LEFT SINGLE QUOTATION MARK (‘)
- `0x92`: RIGHT SINGLE QUOTATION MARK (’)
- `0x93`: LEFT DOUBLE QUOTATION MARK (“)
- `0x94`: RIGHT DOUBLE QUOTATION MARK (“)
- `0x95`: BULLET (•)
- `0x96`: EN DASH (–)
- `0x97`: EM DASH (—)
- `0x99`: TRADE MARK SIGN (™)
- `0x9A`: LATIN SMALL LETTER S WITH CARON (š)
- `0x9B`: SINGLE RIGHT-POINTING ANGLE QUOTATION MARK (›)
- `0x9C`: LATIN SMALL LETTER Z WITH CARON (ž)
- `0x9E`: LATIN SMALL LETTER Z WITH CARON (ž) - duplicate
- `0x9F`: LATIN CAPITAL LETTER Y WITH DIAERESIS (Ÿ)

## Usage Examples

Converting CP1252 to Unicode:
```c
// Using the mapping table in code
uint8_t cp1252_code = 0xE9;  // Windows-1252 code for LATIN SMALL LETTER E WITH ACUTE
uint16_t unicode_code = lookup_cp1252_to_unicode(cp1252_code);  // Returns 0x00E9
```

Converting Unicode to CP1252:
```c
// Reverse lookup (requires building reverse mapping)
uint16_t unicode_code = 0x00E9;  // LATIN SMALL LETTER E WITH ACUTE
uint8_t cp1252_code = lookup_unicode_to_cp1252(unicode_code);  // Returns 0xE9
```
