# KSX1001.TXT Documentation

## Overview

This file contains a mapping table between the KSX1001 (Korean) character encoding and Unicode. KSX1001 is a double-byte character encoding used primarily for Korean text in various computing environments. It supports the Korean script including Hangul syllables and Hanja (Chinese characters) used in Korean.

## File Structure

The file follows a standardized format with three tab-separated columns:
1. **Column 1**: KSX1001 code (in hexadecimal format)
2. **Column 2**: Unicode code point (in hexadecimal format as 0xXXXX)
3. **Column 3**: Unicode character name (following a comment sign '#')

## Key Components

### Character Mapping
The table maps KSX1001 character codes to their corresponding Unicode code points. This enables conversion between the legacy KSX1001 encoding and modern Unicode representations.

### Special Characters
- Single-byte characters (0x00-0x7F): ASCII characters
- Double-byte characters (0x81-0xFE): Full-width characters including:
  - Hangul syllables (0x8141-0xC6FE)
  - Hanja characters (0xC9A1-0xF9FE)
  - Symbols and punctuation marks
  - Punctuation marks specific to Korean text
- Special symbols and currency signs

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Korean text encoding conversions. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- Format A table structure
- Entries ordered by KSX1001 code sequence
- Special handling for double-byte character sequences

### Character Ranges
- ASCII range (0x00-0x7F): Standard ASCII characters
- Double-byte range (0x81-0xFE): Multi-byte Korean characters
- Comprehensive character set for Hangul and Hanja text support

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain KSX1001-encoded Korean characters. The system uses this table to convert between KSX1001 and Unicode representations as needed for proper text processing and transmission.
