# CP866.TXT Documentation

## Overview

This file contains a mapping table between the Code Page 866 (DOS Cyrillic) character encoding and Unicode. Code Page 866 is a single-byte character encoding used primarily for Cyrillic text in DOS environments. It supports Cyrillic script for Russian and other Slavic languages.

## File Structure

The file follows a standardized format with three tab-separated columns:
1. **Column 1**: CP866 code (in hexadecimal format)
2. **Column 2**: Unicode code point (in hexadecimal format as 0xXXXX)
3. **Column 3**: Unicode character name (following a comment sign '#')

## Key Components

### Character Mapping
The table maps CP866 character codes to their corresponding Unicode code points. This enables conversion between the legacy CP866 encoding and modern Unicode representations.

### Special Characters
- Control characters (0x00-0x1F)
- Basic Latin characters (0x20-0x7F)
- Cyrillic-specific characters including:
  - Cyrillic letters (0x80-0xFF)
  - Cyrillic punctuation marks
  - Mathematical symbols
  - Box drawing characters
- Block elements and geometric shapes

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Cyrillic text encoding conversions. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- Format A table structure
- Entries ordered by CP866 code sequence
- Special handling for box drawing and block elements

### Character Ranges
- ASCII range (0x00-0x7F): Standard ASCII characters
- Cyrillic range (0x80-0xFF): Cyrillic-specific characters
- Special symbols for DOS-era applications

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain CP866-encoded Cyrillic characters. The system uses this table to convert between CP866 and Unicode representations as needed for proper text processing and transmission.
