# CP1254.TXT

## Overview

This file contains the character mapping table for Windows-1254 encoding to Unicode. Windows-1254 is a character encoding standard developed by Microsoft for representing Turkish language characters.

The file defines the mapping between Windows-1254 code points and their corresponding Unicode code points. It follows the standard Format A specification with three tab-separated columns.

## Key Information

### File Details
- **Name**: cp1254 to Unicode table
- **Unicode version**: 2.0
- **Table version**: 2.01
- **Table format**: Format A
- **Date**: 04/15/98
- **Contact**: Shawn.Steele@microsoft.com

### Format
The file uses Format A with three tab-separated columns:
1. **cp1254 code** (in hex)
2. **Unicode code** (in hex as 0xXXXX)
3. **Unicode name** (follows a comment sign, '#')

## Important Notes

### Control Characters
Codes 0x00-0x1F and 0x7F represent standard ASCII control characters with their corresponding Unicode mappings.

### Undefined Characters
Several code points are undefined and marked with empty Unicode mappings:
- `0x81`: UNDEFINED
- `0x83`: UNDEFINED
- `0x88`: UNDEFINED
- `0x90`: UNDEFINED
- `0x98`: UNDEFINED
- `0x9A`: UNDEFINED
- `0x9D`: UNDEFINED
- `0x9E`: UNDEFINED
- `0xFF`: UNDEFINED

These undefined characters should be handled appropriately in conversion routines.

### Turkish Character Set
Windows-1254 supports the complete Turkish alphabet with special characters:
- Latin letters with diacritics: Ğğ İı Öö Şş Üü
- Standard Latin letters: ABCDEFGHIJKLMNOPQRSTUVWXYZ
- Lowercase Latin letters: abcdefghijklmnopqrstuvwxyz

Notable differences from other encodings:
- `0xD0`: LATIN CAPITAL LETTER I WITH DOT ABOVE (İ)
- `0xF0`: LATIN SMALL LETTER DOTLESS I (ı)
- `0xD5`: LATIN CAPITAL LETTER G WITH BREVE (Ğ)
- `0xF5`: LATIN SMALL LETTER G WITH BREVE (ğ)
- `0xD6`: LATIN CAPITAL LETTER O WITH DIAERESIS (Ö)
- `0xF6`: LATIN SMALL LETTER O WITH DIAERESIS (ö)
- `0xD7`: MULTIPLICATION SIGN (×)
- `0xF7`: DIVISION SIGN (÷)
- `0xDC`: LATIN CAPITAL LETTER U WITH DIAERESIS (Ü)
- `0xFC`: LATIN SMALL LETTER U WITH DIAERESIS (ü)
- `0xDD`: LATIN CAPITAL LETTER S WITH CEDILLA (Ş)
- `0xFD`: LATIN SMALL LETTER S WITH CEDILLA (ş)

## Usage Examples

Converting CP1254 to Unicode:
```c
// Using the mapping table in code
uint8_t cp1254_code = 0xD0;  // Windows-1254 code for LATIN CAPITAL LETTER I WITH DOT ABOVE
uint16_t unicode_code = lookup_cp1254_to_unicode(cp1254_code);  // Returns 0x0130
```

Converting Unicode to CP1254:
```c
// Reverse lookup (requires building reverse mapping)
uint16_t unicode_code = 0x0130;  // LATIN CAPITAL LETTER I WITH DOT ABOVE
uint8_t cp1254_code = lookup_unicode_to_cp1254(unicode_code);  // Returns 0xD0
```
