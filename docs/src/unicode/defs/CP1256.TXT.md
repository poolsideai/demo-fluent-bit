# CP1256.TXT Documentation

## Overview

This file contains a mapping table between the Code Page 1256 (Arabic) character encoding and Unicode. Code Page 1256 is a single-byte character encoding used primarily for Arabic text in Microsoft Windows environments. It supports Arabic script along with some additional characters for Persian and Urdu languages.

## File Structure

The file follows a standardized format with three tab-separated columns:
1. **Column 1**: CP1256 code (in hexadecimal format)
2. **Column 2**: Unicode code point (in hexadecimal format as 0xXXXX)
3. **Column 3**: Unicode character name (following a comment sign '#')

## Key Components

### Character Mapping
The table maps CP1256 character codes to their corresponding Unicode code points. This enables conversion between the legacy CP1256 encoding and modern Unicode representations.

### Special Characters
- Control characters (0x00-0x1F)
- Basic Latin characters (0x20-0x7F)
- Arabic-specific characters including:
  - Arabic letters (0x80-0xFF)
  - Arabic presentation forms
  - Arabic punctuation marks
  - Digits (0x30-0x39)
- Additional characters for Persian/Urdu support

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Arabic text encoding conversions. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- Format A table structure
- Entries ordered by CP1256 code sequence
- Special handling for presentation forms and contextual variants

### Character Ranges
- ASCII range (0x00-0x7F): Standard ASCII characters
- Arabic range (0x80-0xFF): Arabic-specific characters
- Presentation forms for proper Arabic text rendering

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain CP1256-encoded Arabic characters. The system uses this table to convert between CP1256 and Unicode representations as needed for proper text processing and transmission.
