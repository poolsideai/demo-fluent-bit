# CP936.TXT Documentation

## Overview

This file contains a mapping table between the Code Page 936 (Simplified Chinese GBK) character encoding and Unicode. Code Page 936 is a double-byte character encoding used primarily for Simplified Chinese text in Microsoft Windows environments. It supports the Chinese script including Hanzi (Chinese characters) and other symbols.

## File Structure

The file follows a standardized format with three tab-separated columns:
1. **Column 1**: CP936 code (in hexadecimal format)
2. **Column 2**: Unicode code point (in hexadecimal format as 0xXXXX)
3. **Column 3**: Unicode character name (following a comment sign '#')

## Key Components

### Character Mapping
The table maps CP936 character codes to their corresponding Unicode code points. This enables conversion between the legacy CP936 encoding and modern Unicode representations.

### Special Characters
- Single-byte characters (0x00-0x7F): ASCII characters
- Double-byte characters (0x81-0xFE): Full-width characters including:
  - Level 1 Hanzi characters (0x8140-0xA0FE)
  - Level 2 Hanzi characters (0xA1A1-0xFEFE)
  - Symbols and punctuation marks
  - Punctuation marks specific to Chinese text
- Special symbols and currency signs

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Simplified Chinese text encoding conversions. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- Format A table structure
- Entries ordered by CP936 code sequence
- Special handling for double-byte character sequences

### Character Ranges
- ASCII range (0x00-0x7F): Standard ASCII characters
- Double-byte range (0x81-0xFE): Multi-byte Chinese characters
- Level 1 and Level 2 character sets for comprehensive Chinese text support

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain CP936-encoded Simplified Chinese characters. The system uses this table to convert between CP936 and Unicode representations as needed for proper text processing and transmission.
