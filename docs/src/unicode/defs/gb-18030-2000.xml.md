# gb-18030-2000.xml Documentation

## Overview

This file contains a mapping table between the GB18030 (Chinese) character encoding and Unicode. GB18030 is a multi-byte character encoding used for Simplified Chinese text in China. It's an extension of the GBK encoding and supports a broader range of Chinese characters, including those required by the Chinese government standard.

## File Structure

This file uses an XML format based on the Unicode Character Mapping DTD (Document Type Definition). The structure includes:
- Character mapping definitions with validity states
- Assignment tables with Unicode to byte sequence mappings
- Special handling for multi-byte sequences

## Key Components

### Mapping Structure
The file defines mappings between Unicode code points and their corresponding GB18030 byte sequences. This enables conversion between the legacy GB18030 encoding and modern Unicode representations.

### Special Features
- Support for 1-byte, 2-byte, and 4-byte sequences
- Comprehensive coverage of Chinese characters including:
  - ASCII characters (1-byte)
  - GBK characters (2-byte)
  - Additional Chinese characters (4-byte)
  - Symbols and punctuation marks
- Special encoding for user-defined areas

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Simplified Chinese text encoding conversions according to the GB18030 standard. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- XML-based character mapping format
- Validity state definitions for different byte ranges
- Special handling for multi-byte character sequences

### Character Encoding Ranges
- 1-byte range (0x00-0x7F): ASCII characters
- 2-byte range (0x81-0xFE): GBK-compatible characters
- 4-byte range (0x81-0xFE): Extended Chinese characters

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain GB18030-encoded Simplified Chinese characters. The system uses this table to convert between GB18030 and Unicode representations as needed for proper text processing and transmission according to Chinese government standards.
