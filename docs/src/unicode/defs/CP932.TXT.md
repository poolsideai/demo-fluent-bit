# CP932.TXT Documentation

## Overview

This file contains a mapping table between the Code Page 932 (Japanese Shift-JIS) character encoding and Unicode. Code Page 932 is a double-byte character encoding used primarily for Japanese text in Microsoft Windows environments. It supports the Japanese script including Hiragana, Katakana, and Kanji characters.

## File Structure

The file follows a standardized format with three tab-separated columns:
1. **Column 1**: CP932 code (in hexadecimal format)
2. **Column 2**: Unicode code point (in hexadecimal format as 0xXXXX)
3. **Column 3**: Unicode character name (following a comment sign '#')

## Key Components

### Character Mapping
The table maps CP932 character codes to their corresponding Unicode code points. This enables conversion between the legacy CP932 encoding and modern Unicode representations.

### Special Characters
- Single-byte characters (0x00-0x7F, 0xA1-0xDF): ASCII and half-width katakana
- Double-byte characters (0x81-0x9F, 0xE0-0xEF): Full-width characters including:
  - Hiragana (0x829F-0x82F1)
  - Katakana (0x8340-0x8396)
  - Kanji characters (0x889F-0x9872)
  - Symbols and punctuation marks
- Half-width katakana and special symbols

## Dependencies

This file is used by the Fluent Bit Unicode conversion system to properly handle Japanese text encoding conversions. It works in conjunction with other Unicode definition files and the core Unicode conversion logic.

## Implementation Details

### Format Specification
- Format A table structure
- Entries ordered by CP932 code sequence
- Special handling for double-byte character sequences

### Character Ranges
- ASCII range (0x00-0x7F): Standard ASCII characters
- Half-width katakana (0xA1-0xDF): Single-byte katakana
- Double-byte range (0x81-0x9F, 0xE0-0xEF): Multi-byte Japanese characters

## Usage

This mapping table is automatically used by Fluent Bit when processing text data that may contain CP932-encoded Japanese characters. The system uses this table to convert between CP932 and Unicode representations as needed for proper text processing and transmission.
