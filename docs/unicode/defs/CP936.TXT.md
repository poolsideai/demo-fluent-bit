# CP936.TXT

## Overview

This file contains the Unicode mapping table for the Windows-936 character encoding, also known as CP936 or Windows-936. This is Microsoft's extension of GB2312 for Simplified Chinese text representation.

Windows-936 is used primarily for Simplified Chinese language text processing and is widely used in China. It supports Simplified Chinese characters.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP936 Code Point**: The Windows-936 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-936 is designed specifically for:
- Simplified Chinese

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Simplified Chinese characters (汉字)
- Some special symbols and mathematical operators

## Key Features

### Chinese Character Support

Windows-936 provides comprehensive support for Simplified Chinese text, including:
- Simplified Chinese characters
- Chinese punctuation marks
- Chinese symbols

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)

## Version Information

- Unicode version: 2.0
- Table version: 2.01
- Format: Format A (three-column tab-separated)
- Last updated: 1/7/2000

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-936 encoded text to UTF-8
2. Convert UTF-8 text to Windows-936 encoding
3. Handle character encoding detection and validation
