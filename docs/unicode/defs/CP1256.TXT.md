# CP1256.TXT

## Overview

This file contains the Unicode mapping table for the Windows-1256 character encoding, also known as CP1256 or Windows-1256. This is a character encoding standard developed by Microsoft for Arabic text representation.

Windows-1256 is used primarily for Arabic language text processing and is widely used in Arab countries. It supports Arabic letters, punctuation marks, and some Latin characters.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP1256 Code Point**: The Windows-1256 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-1256 is designed specifically for:
- Arabic

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Arabic letters and punctuation
- Some special symbols and mathematical operators

## Key Features

### Arabic Character Support

Windows-1256 provides comprehensive support for Arabic text, including:
- Arabic letters (ا, ب, ت, ث, ج, ح, خ, د, ذ, ر, ز, س, ش, ص, ض, ط, ظ, ع, غ, ف, ق, ك, ل, م, ن, ه, و, ي)
- Arabic presentation forms
- Arabic punctuation marks
- Arabic diacritical marks

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥, rial)
- Fraction symbols (¼, ½, ¾)

## Version Information

- Unicode version: 2.1
- Table version: 2.01
- Format: Format A (three-column tab-separated)
- Last updated: 01/5/99

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-1256 encoded text to UTF-8
2. Convert UTF-8 text to Windows-1256 encoding
3. Handle character encoding detection and validation
