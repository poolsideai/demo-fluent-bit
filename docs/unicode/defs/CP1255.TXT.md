# CP1255.TXT

## Overview

This file contains the Unicode mapping table for the Windows-1255 character encoding, also known as CP1255 or Windows-1255. This is a character encoding standard developed by Microsoft for Hebrew text representation.

Windows-1255 is used primarily for Hebrew language text processing and is widely used in Israel and other regions where Hebrew is spoken. It supports Hebrew letters, punctuation marks, and some Latin characters.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP1255 Code Point**: The Windows-1255 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-1255 is designed specifically for:
- Hebrew

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Hebrew letters and punctuation
- Some special symbols and mathematical operators

## Key Features

### Hebrew Character Support

Windows-1255 provides comprehensive support for Hebrew text, including:
- Hebrew consonants (א, ב, ג, ד, ה, ו, ז, ח, ט, י, כ, ל, מ, נ, ס, ע, פ, צ, ק, ר, ש, ת)
- Hebrew vowel points (niqqud)
- Hebrew punctuation marks
- Hebrew cantillation marks

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ₪)
- Fraction symbols (¼, ½, ¾)

## Version Information

- Unicode version: 2.0

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-1255 encoded text to UTF-8
2. Convert UTF-8 text to Windows-1255 encoding
3. Handle character encoding detection and validation
