# CP950.TXT

## Overview

This file contains the Unicode mapping table for the Windows-950 character encoding, also known as CP950 or Windows-950. This is Microsoft's extension of Big5 for Traditional Chinese text representation.

Windows-950 is used primarily for Traditional Chinese language text processing and is widely used in Taiwan, Hong Kong, and Macau. It supports Traditional Chinese characters.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP950 Code Point**: The Windows-950 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-950 is designed specifically for:
- Traditional Chinese

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Traditional Chinese characters (漢字)
- Some special symbols and mathematical operators

## Key Features

### Chinese Character Support

Windows-950 provides comprehensive support for Traditional Chinese text, including:
- Traditional Chinese characters
- Chinese punctuation marks
- Chinese symbols

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)

## Version Information

- Unicode version: 2.0
- Table version: 2.01
- Format: Format A (three-column tab-separated)
- Last updated: 1/7/2000

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-950 encoded text to UTF-8
2. Convert UTF-8 text to Windows-950 encoding
3. Handle character encoding detection and validation
