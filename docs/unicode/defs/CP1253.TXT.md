# CP1253.TXT

## Overview

This file contains the Unicode mapping table for the Windows-1253 character encoding, also known as CP1253 or Windows-1253.

Windows-1253 is a character encoding standard developed by Microsoft for Greek language text. It's widely used in Greece and Cyprus for representing text in the Greek alphabet.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP1253 Code Point**: The Windows-1253 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-1253 is designed to support:
- Greek (Modern)
- Greek (Ancient) - with limitations
- Cypriot Greek

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Greek characters and symbols
- Currency symbols
- Mathematical operators
- Box drawing characters
- Block elements

## Key Features

### Greek Alphabet

Windows-1253 supports the complete Greek alphabet with various diacritical marks:
- Capital letters: Α, Β, Γ, Δ, Ε, Ζ, Η, Θ, Ι, Κ, Λ, Μ, Ν, Ξ, Ο, Π, Ρ, Σ, Τ, Υ, Φ, Χ, Ψ, Ω
- Small letters: α, β, γ, δ, ε, ζ, η, θ, ι, κ, λ, μ, ν, ξ, ο, π, ρ, σ, τ, υ, φ, χ, ψ, ω
- Additional characters: Ά, Έ, Ή, Ί, Ό, Ύ, Ώ, ΐ, ΰ, Ϊ, Ϋ, ά, έ, ή, ί, ΰ, ό, ύ, ώ, Ϗ

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)
- Inverted exclamation mark (¡)
- Inverted question mark (¿)

### Diacritical Marks

- Acute accent (´) - Ά, Έ, Ή, Ί, Ό, Ύ, Ώ, ΐ, ΰ, Ϊ, Ϋ, ά, έ, ή, ί, ΰ, ό, ύ, ώ, Ϗ
- Grave accent (`) - Ά, Έ, Ή, Ί, Ό, Ύ, Ώ, ΐ, ΰ, Ϊ, Ϋ, ά, έ, ή, ί, ΰ, ό, ύ, ώ, Ϗ
- Circumflex accent (^) - Ά, Έ, Ή, Ί, Ό, Ύ, Ώ, ΐ, ΰ, Ϊ, Ϋ, ά, έ, ή, ί, ΰ, ό, ύ, ώ, Ϗ
- Diaeresis (¨) - Ά, Έ, Ή, Ί, Ό, Ύ, Ώ, ΐ, ΰ, Ϊ, Ϋ, ά, έ, ή, ί, ΰ, ό, ύ, ώ, Ϗ
- Ring above (˚) - Ά, Έ, Ή, Ί, Ό, Ύ, Ώ, ΐ, ΰ, Ϊ, Ϋ, ά, έ, ή, ί, ΰ, ό, ύ, ώ, Ϗ

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-1253 encoded text to UTF-8
2. Convert UTF-8 text to Windows-1253 encoding
3. Handle character encoding detection and validation
