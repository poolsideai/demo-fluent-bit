# CP1254.TXT

## Overview

This file contains the Unicode mapping table for the Windows-1254 character encoding, also known as CP1254 or Windows-1254.

Windows-1254 is a character encoding standard developed by Microsoft for Turkish language text. It's an extension of ISO 8859-9 (Latin-5) that includes additional printable characters in the 0x80-0x9F range.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP1254 Code Point**: The Windows-1254 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-1254 is designed to support:
- Turkish
- Azerbaijani (Latin script) - with limitations
- Other Turkic languages using Latin script - with limitations

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Latin-1 Supplement characters
- Latin Extended-A characters for Turkish
- Currency symbols
- Mathematical operators
- Box drawing characters
- Block elements

## Key Features

### Turkish Alphabet

Windows-1254 supports the complete Turkish alphabet with special characters:
- Capital letters: A, B, C, Ç, D, E, F, G, Ğ, H, I, İ, J, K, L, M, N, O, Ö, P, R, S, Ş, T, U, Ü, V, Y, Z
- Small letters: a, b, c, ç, d, e, f, g, ğ, h, i, ı, j, k, l, m, n, o, ö, p, r, s, ş, t, u, ü, v, y, z
- Additional characters: Ā, Ă, Ą, Ć, Ĉ, Ċ, Č, Ď, Đ, Ē, Ĕ, Ė, Ę, Ě, Ĝ, Ğ, Ģ, Ĥ, Ħ, Ĩ, Ī, Ĭ, Į, İ, Ĳ, Ĵ, Ķ, Ĺ, Ļ, Ľ, Ŀ, Ł, Ń, Ņ, Ň, Ŋ, Ō, Ŏ, Ő, Œ, Ŕ, Ŗ, Ř, Ś, Ŝ, Ş, Š, Ţ, Ť, Ŧ, Ũ, Ū, Ŭ, Ů, Ű, Ų, Ŵ, Ŷ, Ÿ, Ź, Ż, Ž

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥, ₺)
- Fraction symbols (¼, ½, ¾)
- Inverted exclamation mark (¡)
- Inverted question mark (¿)

### Diacritical Marks

- Acute accent (´) - Á, É, Í, Ó, Ú, Ý, á, é, í, ó, ú, ý
- Grave accent (`) - À, È, Ì, Ò, Ù, à, è, ì, ò, ù
- Circumflex accent (^) - Â, Ă, Ê, Î, Ô, Ş, Û, â, ă, ê, î, ô, ş, û
- Tilde (~) - Ã, Õ, ñ, õ
- Diaeresis (¨) - Ä, Ö, Ÿ, ä, ö, ü, ÿ
- Ring above (˚) - Å, å
- Double acute accent (˝) - Ő, Ű, ő, ű
- Caron (ˇ) - Č, Ď, Ě, Ň, Ř, Š, Ť, Ž, č, ď, ě, ň, ř, š, ť, ž
- Ogonek (˛) - Ą, Ę, Į, Ų, ą, ę, į, ų
- Stroke (/) - Đ, đ

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-1254 encoded text to UTF-8
2. Convert UTF-8 text to Windows-1254 encoding
3. Handle character encoding detection and validation
