# CP874.TXT

## Overview

This file contains the Unicode mapping table for the Windows-874 character encoding, also known as CP874 or Windows-874. This is a character encoding standard developed by Microsoft for Thai text representation.

Windows-874 is used primarily for Thai language text processing and is widely used in Thailand. It supports Thai letters, punctuation marks, and some Latin characters.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP874 Code Point**: The Windows-874 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-874 is designed specifically for:
- Thai

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Thai letters and punctuation
- Some special symbols and mathematical operators

## Key Features

### Thai Character Support

Windows-874 provides comprehensive support for Thai text, including:
- Thai consonants (ก, ข, ฃ, ค, ฅ, ฆ, ง, จ, ฉ, ช, ซ, ฌ, ญ, ฎ, ฏ, ฐ, ฑ, ฒ, ณ, ด, ต, ถ, ท, ธ, น, บ, ป, ผ, ฝ, พ, ฟ, ภ, ม, ย, ร, ฤ, ล, ฦ, ว, ศ, ษ, ส, ห, ฬ, อ, ฮ)
- Thai vowel signs
- Thai tone marks
- Thai punctuation marks

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥, ฿)
- Fraction symbols (¼, ½, ¾)

## Version Information

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-874 encoded text to UTF-8
2. Convert UTF-8 text to Windows-874 encoding
3. Handle character encoding detection and validation
