# CP1252.TXT

## Overview

This file contains the Unicode mapping table for the Windows-1252 character encoding, also known as CP1252 or Windows-1252.

Windows-1252 is a character encoding standard developed by Microsoft for Western European languages. It's an extension of ISO 8859-1 (Latin-1) that includes additional printable characters in the 0x80-0x9F range, which are control characters in ISO 8859-1.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP1252 Code Point**: The Windows-1252 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Latin-1 Supplement characters
- Additional printable characters in the 0x80-0x9F range
- Currency symbols
- Mathematical operators
- Box drawing characters
- Block elements

## Key Features

### Extended Character Set

Windows-1252 extends ISO 8859-1 by replacing the control characters in the 0x80-0x9F range with printable characters:

- Euro sign (€) at 0x80
- Single low-9 quotation mark (‚) at 0x82
- Latin small letter f with hook (ƒ) at 0x83
- Double low-9 quotation mark („) at 0x84
- Horizontal ellipsis (…) at 0x85
- Dagger (†) at 0x86
- Double dagger (‡) at 0x87
- Modifier letter circumflex accent (ˆ) at 0x88
- Per mille sign (‰) at 0x89
- Latin capital letter S with caron (Š) at 0x8A
- Single left-pointing angle quotation mark (‹) at 0x8B
- Latin capital ligature OE (Œ) at 0x8C
- Latin capital letter Z with caron (Ž) at 0x8E
- Single left-pointing angle quotation mark (‹) at 0x8B
- Single right-pointing angle quotation mark (›) at 0x9B
- Latin small letter s with caron (š) at 0x9A
- Latin small ligature oe (œ) at 0x9C
- Latin small letter z with caron (ž) at 0x9E
- Latin capital letter Y with diaeresis (Ÿ) at 0x9F

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥, €)
- Fraction symbols (¼, ½, ¾)
- Inverted exclamation mark (¡)
- Inverted question mark (¿)

### Diacritical Marks

- Acute accent (´) - Á, É, Í, Ó, Ú, Ý, á, é, í, ó, ú, ý
- Grave accent (`) - À, È, Ì, Ò, Ù, à, è, ì, ò, ù
- Circumflex accent (^) - Â, Ă, Ê, Î, Ô, Ş, Û, â, ă, ê, î, ô, ş, û
- Tilde (~) - Ã, Õ, ñ, õ
- Diaeresis (¨) - Ä, Ö, Ÿ, ä, ö, ü, ÿ
- Ring above (˚) - Å, å
- Double acute accent (˝) - Ő, Ű, ő, ű
- Caron (ˇ) - Č, Ď, Ě, Ň, Ř, Š, Ť, Ž, č, ď, ě, ň, ř, š, ť, ž
- Ogonek (˛) - Ą, Ę, Į, Ų, ą, ę, į, ų
- Stroke (/) - Đ, đ
