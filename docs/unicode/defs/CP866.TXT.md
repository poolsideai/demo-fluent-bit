# CP866.TXT

## Overview

This file contains the Unicode mapping table for the CP866 character encoding, also known as DOS Cyrillic. This is a character encoding standard used in DOS environments for Cyrillic script text representation.

CP866 is used primarily for Russian and other Slavic languages that use the Cyrillic alphabet. It's commonly used in DOS environments and legacy systems.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP866 Code Point**: The CP866 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

CP866 is designed for:
- Russian
- Ukrainian
- Belarusian
- Bulgarian
- Serbian (Cyrillic)
- Macedonian
- Other Slavic languages using Cyrillic script

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Cyrillic letters and punctuation
- Some special symbols and mathematical operators

## Key Features

### Cyrillic Character Support

CP866 provides support for Cyrillic text, including:
- Cyrillic letters (А, Б, В, Г, Д, Е, Ж, З, И, Й, К, Л, М, Н, О, П, Р, С, Т, У, Ф, Х, Ц, Ч, Ш, Щ, Ъ, Ы, Ь, Э, Ю, Я)
- Cyrillic small letters (а, б, в, г, д, е, ж, з, и, й, к, л, м, н, о, п, р, с, т, у, ф, х, ц, ч, ш, щ, ъ, ы, ь, э, ю, я)
- Cyrillic punctuation marks

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥, ₽)
- Fraction symbols (¼, ½, ¾)

## Version Information

- Unicode version: 2.0
- Table version: 2.00
- Format: Format A (three-column tab-separated)
- Last updated: 04/24/96

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert CP866 encoded text to UTF-8
2. Convert UTF-8 text to CP866 encoding
3. Handle character encoding detection and validation
