# CNS11643.TXT

## Overview

This file contains the Unicode mapping table for the CNS 11643 character encoding standard, also known as the Taiwan Code for Information Interchange.

CNS 11643 is a national standard of Taiwan that defines character encodings for Chinese characters, including both traditional and simplified forms. It's widely used in Taiwan for government documents, publishing, and digital communications.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CNS11643 Code Point**: The CNS 11643 encoding code in hexadecimal format
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format
3. **Unicode Name**: The official Unicode character name

## Key Features

### Character Coverage
- Traditional Chinese characters
- Simplified Chinese characters
- Latin characters with diacritics
- Greek and Cyrillic characters
- Mathematical symbols
- Technical symbols
- Punctuation marks

### Encoding Planes

CNS 11643 uses multiple planes to organize its character set:
- **Plane 1**: Commonly used characters
- **Plane 2**: Additional characters
- **Plane 3**: Rare characters
- **Plane 4**: Additional rare characters
- **Plane 5**: Additional rare characters
- **Plane 6**: Additional rare characters
- **Plane 7**: Additional rare characters
- **Plane 15**: Additional characters
- **Plane 16**: Additional characters

## Important Notes

### Version Information
- Unicode version: 2.0
- Table version: 2.0
- Format: Format A (three-column tab-separated)
- Last updated: 1994 April 15

### Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert CNS 11643-encoded text to UTF-8
2. Convert UTF-8 text to CNS 11643 encoding
3. Handle character encoding detection and validation

### Limitations

- May not cover all characters in the full CNS 11643 specification
- Some characters may have multiple valid mappings
- Round-trip conversion may not always be lossless
