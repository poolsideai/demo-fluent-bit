# CP1251.TXT

## Overview

This file contains the Unicode mapping table for the Windows-1251 character encoding, also known as CP1251 or Windows-1251.

Windows-1251 is a character encoding standard developed by Microsoft for Cyrillic-based languages. It's widely used in countries such as Russia, Ukraine, Bulgaria, Serbia, Macedonia, and others for representing text in their native Cyrillic scripts.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP1251 Code Point**: The Windows-1251 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-1251 is designed to support the following Cyrillic-based languages:
- Russian
- Ukrainian
- Bulgarian
- Serbian (Cyrillic script)
- Macedonian
- Belarusian
- Kazakh
- Kyrgyz
- Tajik
- Turkmen
- Uzbek
- Mongolian
- Azerbaijani (Cyrillic script)

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Cyrillic characters and symbols
- Currency symbols
- Mathematical operators
- Box drawing characters
- Block elements

## Key Features

### Cyrillic Characters

Windows-1251 supports the complete Cyrillic alphabet with various diacritical marks:
- Capital letters: А, Б, В, Г, Д, Е, Ё, Ж, З, И, Й, К, Л, М, Н, О, П, Р, С, Т, У, Ф, Х, Ц, Ч, Ш, Щ, Ъ, Ы, Ь, Э, Ю, Я
- Small letters: а, б, в, г, д, е, ё, ж, з, и, й, к, л, м, н, о, п, р, с, т, у, ф, х, ц, ч, ш, щ, ъ, ы, ь, э, ю, я
- Additional characters: Ѐ, Ё, Ѓ, Є, Ѕ, І, Ї, Ј, Љ, Њ, Ћ, Ќ, Ѝ, Ў, Џ, А, В, Й, Ё, Щ, Ъ, Ы, Ь, Э, Ю, Я

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ₽)
- Fraction symbols (¼, ½, ¾)
- Inverted exclamation mark (¡)
- Inverted question mark (¿)

### Diacritical Marks

- Acute accent (´) - Ѐ, Ё, Ѓ, Є, Ѕ, І, Ї, Ј, Љ, Њ, Ћ, Ќ, Ѝ, Ў, Џ
- Grave accent (`) - Ѐ
- Circumflex accent (^) - Ѐ, Ё, Ѓ, Є, Ѕ, І, Ї, Ј, Љ, Њ, Ћ, Ќ, Ѝ, Ў, Џ
- Tilde (~) - Ѐ, Ё, Ѓ, Є, Ѕ, І, Ї, Ј, Љ, Њ, Ћ, Ќ, Ѝ, Ў, Џ
- Diaeresis (¨) - Ѐ, Ё, Ѓ, Є, Ѕ, І, Ї, Ј, Љ, Њ, Ћ, Ќ, Ѝ, Ў, Џ
- Ring above (˚) - Ѐ

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-1251 encoded text to UTF-8
2. Convert UTF-8 text to Windows-1251 encoding
3. Handle character encoding detection and validation
