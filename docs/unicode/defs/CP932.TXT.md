# CP932.TXT

## Overview

This file contains the Unicode mapping table for the Windows-932 character encoding, also known as CP932 or Windows-932. This is Microsoft's extension of Shift JIS (SJIS) for Japanese text representation.

Windows-932 is used primarily for Japanese language text processing and is widely used in Japan. It supports Japanese characters including Hiragana, Katakana, and Kanji.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP932 Code Point**: The Windows-932 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-932 is designed specifically for:
- Japanese

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Japanese Hiragana characters
- Japanese Katakana characters
- Japanese Kanji characters
- Some special symbols and mathematical operators

## Key Features

### Japanese Character Support

Windows-932 provides comprehensive support for Japanese text, including:
- Japanese Hiragana (あ, い, う, え, お, ...)
- Japanese Katakana (ア, イ, ウ, エ, オ, ...)
- Japanese Kanji (漢字) characters
- Japanese punctuation marks

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)

## Version Information

- Last updated: 04/15/98

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-932 encoded text to UTF-8
2. Convert UTF-8 text to Windows-932 encoding
3. Handle character encoding detection and validation
