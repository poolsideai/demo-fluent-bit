# windows-949-2000.xml

## Overview

This file contains the Unicode mapping table for the Windows-949 character encoding, also known as Windows-949-2000. This is Microsoft's extension of EUC-KR for Korean text representation.

Windows-949 is used primarily for Korean language text processing and is widely used in Korea. It supports Korean Hangul syllables and Hanja (Chinese characters).

## File Structure

The file follows the Unicode Consortium's Character Mapping Format (TR22) specification using XML format:

1. **Character Mapping Definition**: The root element `<characterMapping>` defines the mapping table
2. **History Section**: Contains modification history with dates and descriptions
3. **Validity Section**: Defines the encoding validity rules
4. **Assignments Section**: Contains the actual character mappings

## Supported Languages

Windows-949 is designed specifically for:
- Korean

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Korean Hangul syllables
- Korean Hanja (Chinese characters)
- Some special symbols and mathematical operators

## Key Features

### Multi-byte Encoding

Windows-949 uses a variable-length encoding scheme:
- Single-byte: 0x00 to 0x80 and 0xFF (ASCII and extended ASCII)
- Double-byte: 0x81 to 0xFE followed by 0x40 to 0x7E or 0x80 to 0xFE

### Korean Character Support

Windows-949 provides comprehensive support for Korean text, including:
- Korean Hangul syllables (가, 나, 다, 라, 마, 바, 사, 아, 자, 차, 카, 타, 파, 하)
- Korean Hanja characters
- Korean punctuation marks
- Korean symbols

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-949 encoded text to UTF-8
2. Convert UTF-8 text to Windows-949 encoding
3. Handle character encoding detection and validation
