# CP1250.TXT

## Overview

This file contains the Unicode mapping table for the Windows-1250 character encoding, also known as CP1250 or Windows-1250.

Windows-1250 is a character encoding standard developed by Microsoft for Central European languages. It's widely used in countries such as Poland, Czech Republic, Slovakia, Hungary, Slovenia, Croatia, and others for representing text in their native languages.

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **CP1250 Code Point**: The Windows-1250 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

Windows-1250 is designed to support the following Central European languages:
- Polish
- Czech
- Slovak
- Hungarian
- Slovenian
- Croatian
- Serbian (Latin script)
- Bosnian
- Romanian
- Albanian
- Macedonian

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Latin-1 Supplement characters with Central European diacritics
- Latin Extended-A characters
- Currency symbols
- Mathematical operators
- Box drawing characters
- Block elements

## Key Features

### Diacritical Marks

Windows-1250 supports various diacritical marks essential for Central European languages:
- Acute accent (´) - Á, É, Í, Ó, Ú, Ý, á, é, í, ó, ú, ý
- Grave accent (`) - À, È, Ì, Ò, Ù, à, è, ì, ò, ù
- Circumflex accent (^) - Â, Ă, Ê, Î, Ô, Ş, Û, â, ă, ê, î, ô, ş, û
- Tilde (~) - Ã, Õ, ñ, õ
- Diaeresis (¨) - Ä, Ö, Ÿ, ä, ö, ü, ÿ
- Caron (ˇ) - Č, Ď, Ě, Ň, Ř, Š, Ť, Ž, č, ď, ě, ň, ř, š, ť, ž
- Ogonek (˛) - Ą, Ę, Į, Ų, ą, ę, į, ų
- Stroke (/) - Đ, đ
- Ring above (˚) - Å, å
- Double acute accent (˝) - Ő, Ű, ő, ű

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert Windows-1250 encoded text to UTF-8
2. Convert UTF-8 text to Windows-1250 encoding
3. Handle character encoding detection and validation
