# KSX1001.TXT

## Overview

This file contains the Unicode mapping table for the KSX1001 character encoding, which is the Korean standard character set for Hangul and Hanja text representation.

KSX1001 is used primarily for Korean language text processing and is widely used in Korea. It supports Korean Hangul syllables and Hanja (Chinese characters).

## File Structure

The file follows the Unicode Consortium's Format A specification with three tab-separated columns:

1. **KSX1001 Code Point**: The KSX1001 encoding code in hexadecimal format (e.g., 0x00)
2. **Unicode Code Point**: The corresponding Unicode code point in hexadecimal format (e.g., 0x0000)
3. **Unicode Name**: The official Unicode character name (e.g., NULL)

## Supported Languages

KSX1001 is designed specifically for:
- Korean

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Korean Hangul syllables
- Korean Hanja (Chinese characters)
- Some special symbols and mathematical operators

## Key Features

### Korean Character Support

KSX1001 provides comprehensive support for Korean text, including:
- Korean Hangul syllables (가, 나, 다, 라, 마, 바, 사, 아, 자, 차, 카, 타, 파, 하)
- Korean Hanja characters
- Korean punctuation marks
- Korean symbols

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert KSX1001 encoded text to UTF-8
2. Convert UTF-8 text to KSX1001 encoding
3. Handle character encoding detection and validation
