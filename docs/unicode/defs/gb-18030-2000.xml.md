# gb-18030-2000.xml

## Overview

This file contains the Unicode mapping table for the GB18030 character encoding standard, which is the Chinese national standard for information interchange.

GB18030 is an extension of GBK that supports all Unicode characters. It's used for Chinese language text processing and is widely used in China. It supports Simplified Chinese characters and all Unicode characters.

## File Structure

The file follows the Unicode Consortium's Character Mapping Format (TR22) specification using XML format:

1. **Character Mapping Definition**: The root element `<characterMapping>` defines the mapping table
2. **History Section**: Contains modification history with dates and descriptions
3. **Validity Section**: Defines the encoding validity rules
4. **Assignments Section**: Contains the actual character mappings

## Supported Languages

GB18030 is designed specifically for:
- Simplified Chinese
- All Unicode languages (through Unicode compatibility)

## Character Coverage

The encoding includes:
- Basic Latin characters (0x00-0x7F)
- Simplified Chinese characters
- All Unicode characters (through four-byte encoding)
- Some special symbols and mathematical operators

## Key Features

### Multi-byte Encoding

GB18030 uses a variable-length encoding scheme:
- Single-byte: 0x00 to 0x7F (ASCII)
- Double-byte: 0x81 to 0xFE followed by 0x40 to 0x7E or 0x80 to 0xFE
- Four-byte: 0x81 to 0xFE followed by 0x30 to 0x39 followed by 0x81 to 0xFE followed by 0x30 to 0x39

### Chinese Character Support

GB18030 provides comprehensive support for Chinese text, including:
- Simplified Chinese characters
- Chinese punctuation marks
- Chinese symbols

### Special Characters

- Section sign (§)
- Paragraph sign (¶)
- Degree sign (°)
- Plus-minus sign (±)
- Multiplication sign (×)
- Division sign (÷)
- Currency symbols (¢, £, ¥)
- Fraction symbols (¼, ½, ¾)

## Version Information

- Unicode version: 3.0

## Usage

This mapping table is used by the Unicode conversion library in Fluent Bit to:
1. Convert GB18030 encoded text to UTF-8
2. Convert UTF-8 text to GB18030 encoding
3. Handle character encoding detection and validation
