# big5_to_utf8.map

This file contains a conversion table that maps Big5 character codes to their corresponding UTF-8 representations.

## Overview

The `big5_to_utf8.map` file is a generated C source file that contains a radix tree data structure for efficiently converting Big5 (Traditional Chinese) encoded text to UTF-8. It is automatically generated by the `src/unicode/maps/UCS_to_BIG5.py` script from Unicode mapping files.

## Structure

The file contains:
1. A radix tree structure (`big5_to_unicode_tree`) that defines the mapping table layout
2. A large array (`big5_to_unicode_tree_table`) containing the actual character mappings

## Key Components

### Radix Tree Structure
```c
static const flb_mb_radix_tree big5_to_unicode_tree = {
  NULL,
  big5_to_unicode_tree_table,
  // Byte range definitions for different code lengths
};
```

### Mapping Table
A large array of 32-bit integers that contains the UTF-8 representations of Big5 characters. The table is organized in segments based on byte patterns for efficient lookup.

## Data Organization

The mapping table is organized using a radix tree approach:
- Single byte mappings (0x00-0xFF)
- Two byte mappings (0xA100-0xF9FF range)
- Three byte mappings (where applicable)
- Four byte mappings (where applicable)

Each segment contains offset information and value mappings for efficient character conversion.

## Usage

This file is compiled as part of Fluent Bit and used by the Unicode conversion subsystem to convert Big5 encoded text to UTF-8. The radix tree structure allows for very fast lookup of character mappings with minimal memory overhead.

## Generation Process

The file is generated by:
1. Running `src/unicode/maps/UCS_to_BIG5.py`
2. Which reads Unicode mapping files from `../defs/`
3. Processes the mappings to create optimized radix tree structures
4. Outputs this C source file

## Dependencies

- Requires the corresponding `utf8_to_big5.map` file for bidirectional conversion
- Used by Fluent Bit's Unicode conversion functions in `src/unicode/`
