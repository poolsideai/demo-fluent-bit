# utf8_to_gb18030.map

This file contains a conversion table that maps UTF-8 encoded characters to their corresponding GB18030 character codes.

## Overview

The `utf8_to_gb18030.map` file is a generated C source file that contains a radix tree data structure for efficiently converting UTF-8 encoded text to GB18030 (Chinese) character codes. It is automatically generated by the `src/unicode/maps/UCS_to_GB18030.py` script from Unicode mapping files.

GB18030 is a character encoding standard used for Simplified Chinese text that extends the GBK encoding to support all Unicode characters.

## Structure

The file contains:
1. A radix tree structure (`gb18030_from_unicode_tree`) that defines the mapping table layout
2. A large array (`gb18030_from_unicode_tree_table`) containing the actual character mappings

## Key Components

### Radix Tree Structure
```c
static const flb_mb_radix_tree gb18030_from_unicode_tree = {
  NULL,
  gb18030_from_unicode_tree_table,
  // Byte range definitions for different code lengths
};
```

### Mapping Table
A large array of 32-bit integers that contains the GB18030 character codes for UTF-8 characters. The table is organized in segments based on byte patterns for efficient lookup.

## Data Organization

The mapping table is organized using a radix tree approach:
- Single byte mappings (0x00-0xFF for ASCII characters)
- Multi-byte mappings for UTF-8 characters (up to 4 bytes)

Each segment contains offset information and value mappings for efficient character conversion.

## Usage

This file is compiled as part of Fluent Bit and used by the Unicode conversion subsystem to convert UTF-8 encoded text to GB18030. The radix tree structure allows for very fast lookup of character mappings with minimal memory overhead.

## Generation Process

The file is generated by:
1. Running `src/unicode/maps/UCS_to_GB18030.py`
2. Which reads Unicode mapping files from `../defs/`
3. Processes the mappings to create optimized radix tree structures
4. Outputs this C source file

## Dependencies

- Requires the corresponding `gb18030_to_utf8.map` file for bidirectional conversion
- Used by Fluent Bit's Unicode conversion functions in `src/unicode/`

## Special Features

GB18030 is a character encoding standard used for Simplified Chinese text. This mapping file handles:
- Basic ASCII characters (0x00-0x7F)
- Simplified Chinese characters in the GB18030 encoding scheme
- Proper handling of multi-byte UTF-8 sequences
- Efficient lookup for common Chinese characters

The radix tree implementation is optimized for UTF-8 byte patterns, providing fast conversion performance for Chinese text processing. This file works in conjunction with `gb18030_to_utf8.map` to provide bidirectional conversion capabilities.
