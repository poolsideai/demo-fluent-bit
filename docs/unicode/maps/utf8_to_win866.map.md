# utf8_to_win866.map

## Overview

This file contains a mapping table for converting UTF-8 encoded characters to Windows-866 (Cyrillic) encoded characters. It implements a radix tree data structure for efficient character encoding conversion.

## Key Components

### `win866_from_unicode_tree_table`

A static array of 16-bit unsigned integers that serves as the lookup table for the radix tree conversion.

### `win866_from_unicode_tree`

A `flb_mb_radix_tree` structure that defines the radix tree for UTF-8 to Windows-866 conversion.

## Important Variables

- `win866_from_unicode_tree_table`: Contains the mapping data organized in a radix tree structure
- `win866_from_unicode_tree`: Defines the tree structure with pointers to the table and configuration parameters

## Dependencies

- Part of the Fluent Bit unicode conversion system
- Generated by `src/unicode/maps/UCS_to_most.py`
- Used by the unicode conversion functions in `src/unicode/`

## Implementation Details

The file implements a multi-level radix tree lookup system:

1. **Dummy map**: Handles invalid UTF-8 sequences (offset 0x00000)
2. **Two-byte table**: Processes UTF-8 sequences with two bytes
3. **Three-byte table**: Processes UTF-8 sequences with three bytes

Each level contains offset pointers to navigate the tree structure efficiently. The table uses a compact representation where trailing zeros are shared between segments to minimize memory usage.

## Usage

This mapping is used internally by Fluent Bit's unicode conversion functions to efficiently convert UTF-8 text to Windows-866 (Cyrillic) encoding. The radix tree structure allows for fast lookup of character mappings with minimal memory overhead.

The conversion process navigates the tree based on the UTF-8 byte sequence, following the offset pointers to reach the appropriate leaf node containing the Windows-866 character code.
