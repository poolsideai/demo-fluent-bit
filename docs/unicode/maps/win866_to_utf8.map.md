# win866_to_utf8.map

## Overview

This file contains a mapping table for converting characters from the Windows-866 (Cyrillic) encoding to UTF-8. It defines a static lookup table that maps single-byte Windows-866 characters to their corresponding Unicode code points.

## Key Components

### Data Structures

- `win866_to_unicode_tree_table`: A static array of 256 uint32_t values representing the mapping from Windows-866 to Unicode
- `win866_to_unicode_tree`: A radix tree structure that provides metadata about the mapping table

### Mapping Table

The table contains two main sections:
1. **Dummy map**: Entries for invalid values (0x00-0x7F) that map to 0x00000000
2. **Single byte table**: Entries for valid Windows-866 characters (0x80-0xFF) that map to their corresponding Unicode code points

## Important Variables

- `win866_to_unicode_tree_table`: The main lookup table with 256 entries
- `win866_to_unicode_tree`: Radix tree structure with metadata about the mapping

## Dependencies

This file is generated by `src/unicode/maps/UCS_to_most.py` and is used by the Unicode conversion system in Fluent Bit.

## Implementation Details

The mapping uses a radix tree approach for efficient character conversion:
- Characters 0x00-0x7F map to 0 (invalid in Windows-866)
- Characters 0x80-0xFF map to their corresponding Unicode values
- The table includes mappings for Cyrillic characters and special symbols

## Usage

This mapping table is used internally by Fluent Bit's Unicode conversion functions to convert text from Windows-866 encoding to UTF-8. It's part of the broader character encoding support system that allows Fluent Bit to handle various input encodings.
