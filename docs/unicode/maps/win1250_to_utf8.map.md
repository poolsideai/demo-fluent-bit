# win1250_to_utf8.map

## Overview

This file contains a mapping table for converting Windows-1250 encoded characters to UTF-8 encoded characters. It implements a radix tree data structure for efficient character encoding conversion.

## Key Components

### `win1250_to_unicode_tree_table`

A static array of 32-bit unsigned integers that serves as the lookup table for the radix tree conversion.

### `win1250_to_unicode_tree`

A `flb_mb_radix_tree` structure that defines the radix tree for Windows-1250 to UTF-8 conversion.

## Important Variables

- `win1250_to_unicode_tree_table`: Contains the mapping data organized in a radix tree structure
- `win1250_to_unicode_tree`: Defines the tree structure with pointers to the table and configuration parameters

## Dependencies

- Part of the Fluent Bit unicode conversion system
- Generated by `src/unicode/maps/UCS_to_most.py`
- Used by the unicode conversion functions in `src/unicode/`

## Implementation Details

The file implements a multi-level radix tree lookup system:

1. **Dummy map**: Handles invalid Windows-1250 sequences (offset 0x00000)
2. **Single byte table**: Processes Windows-1250 single byte characters

Each level contains offset pointers to navigate the tree structure efficiently. The table uses a compact representation where trailing zeros are shared between segments to minimize memory usage.

## Usage

This mapping is used internally by Fluent Bit's unicode conversion functions to efficiently convert Windows-1250 text to UTF-8 encoding. The radix tree structure allows for fast lookup of character mappings with minimal memory overhead.

The conversion process navigates the tree based on the Windows-1250 byte sequence, following the offset pointers to reach the appropriate leaf node containing the UTF-8 character code. The resulting UTF-8 codes are stored as 32-bit values in the lookup table.
