# sjis_to_utf8.map

This file contains a conversion table that maps Shift-JIS character codes to their corresponding UTF-8 representations.

## Overview

The `sjis_to_utf8.map` file is a generated C source file that contains a radix tree data structure for efficiently converting Shift-JIS (Japanese) encoded text to UTF-8. It is automatically generated by the `src/unicode/maps/UCS_to_SJIS.py` script from Unicode mapping files.

## Structure

The file contains:
1. A radix tree structure (`sjis_to_unicode_tree`) that defines the mapping table layout
2. A large array (`sjis_to_unicode_tree_table`) containing the actual character mappings

## Key Components

### Radix Tree Structure
```c
static const flb_mb_radix_tree sjis_to_unicode_tree = {
  NULL,
  sjis_to_unicode_tree_table,
  // Byte range definitions for different code lengths
};
```

### Mapping Table
A large array of 32-bit integers that contains the UTF-8 representations of Shift-JIS characters. The table is organized in segments based on byte patterns for efficient lookup.

## Data Organization

The mapping table is organized using a radix tree approach:
- Single byte mappings (0x00-0xFF for ASCII and half-width katakana)
- Two byte mappings (various ranges for full-width characters)

Each segment contains offset information and value mappings for efficient character conversion.

## Usage

This file is compiled as part of Fluent Bit and used by the Unicode conversion subsystem to convert Shift-JIS encoded text to UTF-8. The radix tree structure allows for very fast lookup of character mappings with minimal memory overhead.

## Generation Process

The file is generated by:
1. Running `src/unicode/maps/UCS_to_SJIS.py`
2. Which reads Unicode mapping files from `../defs/`
3. Processes the mappings with special handling for certain SJIS codes
4. Outputs this C source file

## Dependencies

- Requires the corresponding `utf8_to_sjis.map` file for bidirectional conversion
- Used by Fluent Bit's Unicode conversion functions in `src/unicode/`

## Special Features

Shift-JIS is a character encoding standard used for Japanese text. This mapping file handles:
- Basic ASCII characters (0x00-0x7F)
- Half-width katakana characters
- Full-width hiragana, katakana, and kanji characters
- Special handling for certain SJIS codes that should only be used for SJIS=>UTF8 conversion
- Additional mappings for characters not present in the source file

The radix tree implementation is optimized for the specific byte patterns used in Shift-JIS encoding, providing fast conversion performance for Japanese text processing. The script includes special logic to reject certain SJIS codes for UTF8=>SJIS conversion to avoid conflicts.
