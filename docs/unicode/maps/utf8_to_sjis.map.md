# utf8_to_sjis.map

This file contains a conversion table that maps UTF-8 encoded characters to their corresponding Shift JIS character codes.

## Overview

The `utf8_to_sjis.map` file is a generated C source file that contains a radix tree data structure for efficiently converting UTF-8 encoded text to Shift JIS (Japanese) character codes. It is automatically generated by the `src/unicode/maps/UCS_to_SJIS.py` script from Unicode mapping files.

Shift JIS is a character encoding standard used for Japanese text.

## Structure

The file contains:
1. A radix tree structure (`sjis_from_unicode_tree`) that defines the mapping table layout
2. A large array (`sjis_from_unicode_tree_table`) containing the actual character mappings

## Key Components

### Radix Tree Structure
```c
static const flb_mb_radix_tree sjis_from_unicode_tree = {
  NULL,
  sjis_from_unicode_tree_table,
  // Byte range definitions for different code lengths
};
```

### Mapping Table
A large array of 32-bit integers that contains the Shift JIS character codes for UTF-8 characters. The table is organized in segments based on byte patterns for efficient lookup.

## Data Organization

The mapping table is organized using a radix tree approach:
- Single byte mappings (0x00-0xFF for ASCII characters)
- Multi-byte mappings for UTF-8 characters (up to 2 bytes)

Each segment contains offset information and value mappings for efficient character conversion.

## Usage

This file is compiled as part of Fluent Bit and used by the Unicode conversion subsystem to convert UTF-8 encoded text to Shift JIS. The radix tree structure allows for very fast lookup of character mappings with minimal memory overhead.

## Generation Process

The file is generated by:
1. Running `src/unicode/maps/UCS_to_SJIS.py`
2. Which reads Unicode mapping files from `../defs/`
3. Processes the mappings to create optimized radix tree structures
4. Outputs this C source file

## Dependencies

- Requires the corresponding `sjis_to_utf8.map` file for bidirectional conversion
- Used by Fluent Bit's Unicode conversion functions in `src/unicode/`

## Special Features

Shift JIS is a character encoding standard used for Japanese text. This mapping file handles:
- Basic ASCII characters (0x00-0x7F)
- Japanese characters in the Shift JIS encoding scheme
- Proper handling of multi-byte UTF-8 sequences
- Efficient lookup for common Japanese characters

The radix tree implementation is optimized for UTF-8 byte patterns, providing fast conversion performance for Japanese text processing. This file works in conjunction with `sjis_to_utf8.map` to provide bidirectional conversion capabilities.
