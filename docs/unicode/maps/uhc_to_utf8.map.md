# uhc_to_utf8.map

This file contains a conversion table that maps Unified Hangul Code (UHC) character codes to their corresponding UTF-8 representations.

## Overview

The `uhc_to_utf8.map` file is a generated C source file that contains a radix tree data structure for efficiently converting UHC (Unified Hangul Code, also known as CP949) encoded text to UTF-8. It is automatically generated by the `src/unicode/maps/USC_to_UHC.py` script from XML mapping files.

## Structure

The file contains:
1. A radix tree structure (`uhc_to_unicode_tree`) that defines the mapping table layout
2. A large array (`uhc_to_unicode_tree_table`) containing the actual character mappings

## Key Components

### Radix Tree Structure
```c
static const flb_mb_radix_tree uhc_to_unicode_tree = {
  NULL,
  uhc_to_unicode_tree_table,
  // Byte range definitions for different code lengths
};
```

### Mapping Table
A large array of 32-bit integers that contains the UTF-8 representations of UHC characters. The table is organized in segments based on byte patterns for efficient lookup.

## Data Organization

The mapping table is organized using a radix tree approach:
- Single byte mappings (0x00-0xFF for ASCII characters)
- Two byte mappings (various ranges for Korean characters)

Each segment contains offset information and value mappings for efficient character conversion.

## Usage

This file is compiled as part of Fluent Bit and used by the Unicode conversion subsystem to convert UHC encoded text to UTF-8. The radix tree structure allows for very fast lookup of character mappings with minimal memory overhead.

## Generation Process

The file is generated by:
1. Running `src/unicode/maps/USC_to_UHC.py`
2. Which reads XML mapping files from `../defs/`
3. Processes the mappings with special filtering
4. Adds one extra character mapping not present in the source file
5. Outputs this C source file

## Dependencies

- Requires the corresponding `utf8_to_uhc.map` file for bidirectional conversion
- Used by Fluent Bit's Unicode conversion functions in `src/unicode/`

## Special Features

UHC (Unified Hangul Code) is a character encoding standard used for Korean text. This mapping file handles:
- Basic ASCII characters (0x00-0x7F)
- Korean Hangul syllables and Jamo characters
- Special filtering to exclude certain codes (0x0080 and 0x00FF)
- Only includes mappings where both code and Unicode values are above 0x80
- One additional character mapping for CIRCLED HANGUL IEUNG U that's not in the source file

The radix tree implementation is optimized for the specific byte patterns used in UHC encoding, providing fast conversion performance for Korean text processing. The script parses XML mapping files using regular expressions to extract the character mappings.
