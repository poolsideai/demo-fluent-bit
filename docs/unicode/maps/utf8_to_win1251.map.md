# utf8_to_win1251.map

This file contains a conversion table that maps UTF-8 encoded characters to their corresponding Windows-1251 character codes.

## Overview

The `utf8_to_win1251.map` file is a generated C source file that contains a radix tree data structure for efficiently converting UTF-8 encoded text to Windows-1251 (Cyrillic) character codes. It is automatically generated by the `src/unicode/maps/UCS_to_Most.py` script from Unicode mapping files.

Windows-1251 is a character encoding standard used for Cyrillic languages including Russian, Bulgarian, Serbian (Cyrillic), Macedonian, and others.

## Structure

The file contains:
1. A radix tree structure (`win1251_from_unicode_tree`) that defines the mapping table layout
2. A large array (`win1251_from_unicode_tree_table`) containing the actual character mappings

## Key Components

### Radix Tree Structure
```c
static const flb_mb_radix_tree win1251_from_unicode_tree = {
  NULL,
  win1251_from_unicode_tree_table,
  // Byte range definitions for different code lengths
};
```

### Mapping Table
A large array of 32-bit integers that contains the Windows-1251 character codes for UTF-8 characters. The table is organized in segments based on byte patterns for efficient lookup.

## Data Organization

The mapping table is organized using a radix tree approach:
- Single byte mappings (0x00-0xFF for ASCII characters)
- Special mappings for extended Cyrillic characters

Each segment contains offset information and value mappings for efficient character conversion.

## Usage

This file is compiled as part of Fluent Bit and used by the Unicode conversion subsystem to convert UTF-8 encoded text to Windows-1251. The radix tree structure allows for very fast lookup of character mappings with minimal memory overhead.

## Generation Process

The file is generated by:
1. Running `src/unicode/maps/UCS_to_Most.py`
2. Which reads Unicode mapping files from `../defs/`
3. Processes the mappings to create optimized radix tree structures
4. Outputs this C source file

## Dependencies

- Requires the corresponding `win1251_to_utf8.map` file for bidirectional conversion
- Used by Fluent Bit's Unicode conversion functions in `src/unicode/`

## Special Features

Windows-1251 is a character encoding standard used for Cyrillic languages. This mapping file handles:
- Basic ASCII characters (0x00-0x7F)
- Cyrillic characters in the Windows-1251 encoding scheme
- Proper handling of multi-byte UTF-8 sequences
- Efficient lookup for common Cyrillic characters

The radix tree implementation is optimized for UTF-8 byte patterns, providing fast conversion performance for Cyrillic text processing. This file works in conjunction with `win1251_to_utf8.map` to provide bidirectional conversion capabilities.
