# gbk_to_utf8.map

This file contains a conversion table that maps GBK character codes to their corresponding UTF-8 representations.

## Overview

The `gbk_to_utf8.map` file is a generated C source file that contains a radix tree data structure for efficiently converting GBK (Simplified Chinese) encoded text to UTF-8. It is automatically generated by the `src/unicode/maps/UCS_to_GBK.py` script from Unicode mapping files.

## Structure

The file contains:
1. A radix tree structure (`gbk_to_unicode_tree`) that defines the mapping table layout
2. A large array (`gbk_to_unicode_tree_table`) containing the actual character mappings

## Key Components

### Radix Tree Structure
```c
static const flb_mb_radix_tree gbk_to_unicode_tree = {
  NULL,
  gbk_to_unicode_tree_table,
  // Byte range definitions for different code lengths
};
```

### Mapping Table
A large array of 32-bit integers that contains the UTF-8 representations of GBK characters. The table is organized in segments based on byte patterns for efficient lookup.

## Data Organization

The mapping table is organized using a radix tree approach:
- Single byte mappings (0x00-0xFF)
- Two byte mappings (0x8140-0xFEFE range for GBK)

Each segment contains offset information and value mappings for efficient character conversion.

## Usage

This file is compiled as part of Fluent Bit and used by the Unicode conversion subsystem to convert GBK encoded text to UTF-8. The radix tree structure allows for very fast lookup of character mappings with minimal memory overhead.

## Generation Process

The file is generated by:
1. Running `src/unicode/maps/UCS_to_GBK.py`
2. Which reads Unicode mapping files from `../defs/`
3. Processes the mappings to create optimized radix tree structures
4. Outputs this C source file

## Dependencies

- Requires the corresponding `utf8_to_gbk.map` file for bidirectional conversion
- Used by Fluent Bit's Unicode conversion functions in `src/unicode/`

## Special Features

GBK is a character encoding standard used for Simplified Chinese. This mapping file handles:
- Basic ASCII characters (0x00-0x7F)
- GBK character set with approximately 21,886 characters
- Proper handling of lead and trail bytes in the GBK encoding scheme
- Efficient lookup for common Chinese characters

The radix tree implementation is optimized for the specific byte patterns used in GBK encoding, providing fast conversion performance for Chinese text processing.
